# Legacy Migration

Using an older jailbreak which has a `Run Hotfix` file? 

You can do this to install KPM, and a jailbreaking manager.

<p class="warning"> 
    Note that, if you are upgrading to 5.19.4+ after doing this, KUAL is no longer supported.<br/>
    In fact, most KPM packages will install directly as <b>scriptlets</b>, not as KUAL extensions.
</p>

## Steps

1. <b>Ensure</b> Wi-Fi is enabled on your Kindle. On a computer, download <a href="./migration.sh" download>this scriptlet</a>.
2. Plug the Kindle into a computer, and copy it to the `documents` folder.
3. Disconnect, when it appears, tap the "Migration" booklet on the homescreen.
4. It will automatically complete the process and reboot.

You're done!

## Notes

You <i>might</i> have to reinstall certain homebrew or applications which are no longer supported, but most of your scriptlets will remain intact.
